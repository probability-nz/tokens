# Blank dice

The D4, D6, D8, D10, D12 and D20 use the same geometry buffers, vertex normals and face rotations as their numbered counterparts. The blank models have a white material. Keep the adjacent numbered-model directories when copying this collection.

Adapted from models by Misha Tsyatsko for Garbo Succus. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
