SHARED DICE FONT — Comic Neue Bold

Install ComicNeue-Bold.ttf in your operating system, then select Comic Neue Bold
in Photoshop, Affinity, Illustrator, Krita, or another text-capable art editor.
The complete original font is included, not a digit-only subset.

All numbered dice use this same font file. Artwork uses 90% horizontal scale,
close digit spacing (4% of numeral height), and a side dot for standalone 6/9.
The letterforms are fitted to each die's flat faces with consistent clearance.
D4 retains three corner labels per face. The classic die retains round pips.

The font file is unmodified and is distributed under SIL OFL 1.1; see OFL.txt.
Keep that license with copies of the font. The surrounding dice assets retain
their own license. source.json records the upstream revision and SHA-256.

Typeface: https://github.com/crozynski/comicneue
Visual proportion reference: Chessex opaque white/black CHX25401 and ivory/black
CHX25400 product photos (Gnomish Bazaar and Super Retro). This is an approximate
visual match, not an exact reproduction of Chessex tooling or lettering.
