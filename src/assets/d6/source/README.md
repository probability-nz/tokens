# Original artwork inputs

These historical commissioned files are retained for reproducible artwork
baking. Their geometry, UVs and normals are not the current dice models.

Use the published model one directory above for import, `../regular/` for the
current generated mesh, and `../paint/` for Photoshop-friendly painting layers.
Regenerate current geometry with `scripts/assets/regular-dice.py`; do not edit
these original inputs to change rounding or UV layout.
