# Chessmen and checker discs

The chessmen come from the Probability chess game at revision 30d1fc706e6e11073f005aece6619c52a857b0cd. The checker discs come from the Probability checkers game at revision 204eeae6a145ba18f7c166fdcb49fd36b1700535. The checkers game generates the rounded disc geometry and embossed ring. Catalog rotations reproduce the starting orientations in those games.

Both source repositories credit Jarlan Perez under CC BY 3.0. See the original [chess notice](chess/LICENSE.md) and [checkers notice](checkers/LICENSE.md). For reuse here, the models reference sibling geometry buffers and carry an attribution field. The red checker is a Probability color variant with a white ring matching the black checker. It shares the original checker geometry, normals, and material finish.
